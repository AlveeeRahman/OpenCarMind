Board

Connect the board to this computer with a USB cable. Changes are refused while the car is connected, so do this parked.

Connection

Wi-Fi networks

The board uses Wi-Fi to set its clock. It joins 2.4 GHz networks only and keeps passwords in its flash as plain text, so a phone hotspot or a guest network is the better choice.

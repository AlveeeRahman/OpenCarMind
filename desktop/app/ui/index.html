Board

Connect the board to this computer with its USB cable. Everything is set up from here, so the SD card stays in the board. Do it with the car parked: the board refuses changes while it is talking to the car.

Pair this board with this app

The board shows a 6-digit code on its screen for 2 minutes. Typing it here proves you have that board in front of you. You only do this once per board.

Wi-Fi networks on the board

The board uses Wi-Fi to set its clock and to send its drives to this app. It joins 2.4 GHz networks only and keeps passwords in its flash as plain text, so a phone hotspot or a guest network is the better choice.

    Time zone and settings

    filled in from this computer. The board uses it for its clock and for light mode from 06:00 to 17:00

    Leave a setting empty to keep the board's value. The board applies settings after a restart.

    Drives on the card

    Copies new drives from the board's SD card over the cable into the same folder the Wi-Fi upload uses. About 15 KB/s, so a long drive takes a few minutes.

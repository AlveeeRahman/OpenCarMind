DEPLOY, to the ESP32-S3

Windows and labels

Optuna tries 150 designs, picked on validation
QAT
quantisation-aware training: every forward pass rounds to the int8 grid, power-of-two scales
Refine
other-car augmentation, real row spacing, 3 seeds, QAT
Test once
last 20 % of each drive, read one time
Export to ONNX
a float twin of the trained network
Quantise with ESP-PPQ
w8a16: 8-bit weights, 16-bit activations, calibrated on all three sources
Check the int8 graph
int8 matches float on 99.9 % of test windows
Generate parameters
ml_params.h: channels, norms, classes, model hash
Build the firmware
model embedded, run by ESP-DL
Check on the board
self-test at boot, then a test drive
score too low? adjust and retrain
int8 drops? refine again
export
Training happens off the board. Quantisation-aware training teaches the network to live on the int8 grid, ESP-PPQ converts it for the chip, and two checks (the int8 score and the board's own self-test) decide whether it ships.
